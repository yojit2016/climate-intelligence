# Dashboard screenshots

This directory is reserved for genuine screenshots captured from the running
application. No screenshot files are currently included.

To add a preview:

1. Run the app using the instructions in the root README.
2. Capture the actual dashboard state you want to document. For IMD views,
   import a real dataset first; do not fabricate or synthesize displayed data.
3. Save optimized PNG or WebP images here with descriptive names such as
   `overview.png`, `imd-heatmap.png`, `date-comparison.png`,
   `ml-evaluation.png`, or `data-processing.png`.
4. Add the image to the README's Dashboard preview section with concise
   alternative text and a caption. Do not include secrets, personal data, or
   data whose source terms do not permit redistribution.
